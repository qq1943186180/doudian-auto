## 2026-10-29 程序改动

1. `--endpoint ego` 使用 Ego 原生 TaskSpace，沿用 SQLite 队列和单写入器。每轮写独立 UTF-8 脚本与输入/结果文件；同一未结束任务固定 TaskSpace，按页面路径复用标签。任务结束后只清理自己的标签，不枚举或修改浏览器配置。
2. 页面文字观察不依赖 Ego 的 snapshot ref 文件；输入和点击先检查当前 DOM 的唯一目标、几何尺寸和命中元素，再用原生鼠标/键盘。文件上传仍走页面 file input。`EPERM/refs.json`、超时和对话框均停止本次操作，不重放保存。
3. 网络事件在动作所在 Node 轮内采集，保留商品读取/上传/保存请求的本地响应证据，不记录请求头和 Cookie。请求证据带页面、轮次和原请求ID，防止跨页面混淆；最多保留最近200个请求。上传动作上限60秒，其他动作30秒观察预算，进程还留少量清理时间。
4. 妙手快捷编辑以当前可命中的精确商品ID行定位，排除屏外克隆行与隐藏祖先；真正可操作的重复行会拒绝。读取商品时排除点击前的请求ID，校验精确商品ID和 `isDraft=0`，再比较实际编辑窗标题。列表摘要不作为保存结果。
5. 批量保存只把明确商品保存接口、相同商品ID、完成HTTP200响应及明确业务 `result` 计为受理/拒绝。其他POST、统计请求、`saveTempBatchTask`、HTTP错误和丢失响应均不作成功或可重存的证据。每次意图只点一次，之后走双端新读取；旧标题允许有限再读，完整图片和保护字段比较仍独立执行。
6. 新素材要求逐图检查记录：商品事实、原图、提示词、目标版本、每张新图全部绑定SHA256；检查身份、颜色、数量、印字、规格。程序检查记录完整性和文件不变性，视觉判断由agent完成。首个失败候选允许同槽重做一次，第二次失败隔离商品；已通过槽位复用。原图上传测试不可计为全部换新。
7. 新上传槽位必须与本地图片字节或解码像素一致；异步转永久素材后还要重新确认。写入器版本升级为 `multi-field-20261029-v3`，旧版本验收证明不能打开当前通用写入器。
8. 实页新建后台Page曾为0×0；窗口尺寸变化还使官方SKU区域由167个输入变为173个。现在每个TaskSpace固定首次实际测量的页面尺寸，零尺寸页使用该尺寸初始化，后续窗口变化不改变本任务视口。保护字段仍严格比较，未增加“子集容忍”。
9. 商品ID输入框聚焦会变成textarea、失焦变回input，按同名字段核对原生输入前后值。商品标题仅取实际 `input[name=name]`，排除同一标签里的“算法热词”控件；等待新读取与当前窗标题一致。
10. 批量页默认显示范围页签，先识别实际商品ID页签，再填写；路由必须包含 `batchType=multi_field`。点击前即时滚动，勾选后读回状态。主图使用 `.replace-image-dialog`；详情使用 `.select-product-filter-dialog` 的本地上传/链接页签。
11. 已有详情来源一致就跳过，避免点击已填图时取消父级复选框。已有目标槽位即使未落库映射也先核对文件内容，匹配则复用，不匹配即停止。完整预览必须是原全部详情、新前4张及原尾图，缺图或尾图换序都拒绝。
