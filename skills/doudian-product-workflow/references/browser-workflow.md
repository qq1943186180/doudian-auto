# 抖店编辑器实测（2026-10-21）

4款在销霁百货提交成功并重开读回。选择器必须现场确认，页面改版时不能盲目重试。

- 列表 `https://fxg.jinritemai.com/ffa/g/list`；从目标ID所在行进入「编辑」。编辑地址按实际新页面读取，勿猜类目参数。
- `#pg-title-input` 是标题。
- `[id^="goodsEditScrollContainer-"]` 是分区。主要是基础信息、图文信息、价格库存、服务与履约；部分商品有尺码表。
- `[attr-field-id="主图"]` 为方图，3:4和白底是其他字段，除非用户要求不要默默一起替换。
- 每格 `.styles-module_hoverBottomWrapper__YPnf1 > div` 第二项为删除，第一项打开AI工具。
- 5格全部空时，主图字段内 `label:last` 可批量上传5张；`label:first` 曾只触发悬浮菜单，未打开文件选择器。先等待filechooser事件，再点真实上传label；事件超时要捕获，避免整个会话重置。
- 标准详情删除 `i.styles_iconDelete__y_88a`；图文区里含「上传图片」的最后一个label是标准详情上传入口。先读旧图数量再逐一删除。隐藏的高级编辑DOM内也有上传label，不能选错。
- 避免为了批量替换进入「高级编辑」；它有独立状态和返回确认。若进入，先检查遮罩与返回保存提示，再恢复标准编辑器。
- 图片上传异步：上传调用返回后再次观察数量和远程地址，再决定下一步；提交点击后也应等下一次状态观察，勿立刻判断失败并重复提交。
- 「填写检查」→检查真实错误→「发布商品」→成功页→「编辑商品」重开。成功页提示1–2工作日审核，不能仅凭此宣称消费者端已更新。
- 详情有懒加载占位图。只记录实际CDN图片，排除UI图标、svg、1px gif和blob地址；隐藏编辑器可能有重复图片，核验时按远程URL去重。
- 浏览器连接出错先用已选浏览器的文档排查。勿重载有未保存编辑的页面。浏览器调用曾从约21秒恢复至1秒内，不能固定sleep；观察当前状态决定操作。

## 快照格式

由授权浏览器的只读DOM采集产生UTF-8 JSON：

```json
{
  "title": "商品标题",
  "sections": [{
    "id": "goodsEditScrollContainer-价格库存",
    "text": "实际可见分区文字，含SKU编号",
    "inputs": [{"value": "20.88", "type": "text"}],
    "images": [{"field": "主图", "src": "https://实际商品图片CDN/图片", "w": 1254, "h": 1254}]
  }]
}
```

采集各分区innerText、input当前值和类型、img的currentSrc或src及naturalWidth/Height；勿读取框架内部状态、Cookie或存储。虚拟表格若只渲染部分SKU，滚动采集或明确标示覆盖范围。

## 本次经验

- 绑带改类目后平台强制售后保障15天→90天，且原退货限制不可选。此类改动必须记录，不能概括成所有商业字段都未变。
- 吸音棉原缺品牌、背胶属性。无背胶SKU已下架，在售SKU均自粘，故补「无品牌」「背胶=是」。此结论只适用该款，不是其他商品的默认值。
- 图片中的防火、防水、通用适配、厂商/认证等宣传不足以证明事实。新文案优先写可见结构、已确认参数及选购条件。
